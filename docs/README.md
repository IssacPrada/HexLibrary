# Welcome to Hex Scripts

Hex Scripts UI Library is a premium, lightweight, and fluid UI library engineered for Roblox exploit developers who want clean aesthetics and professional performance.

## ✨ Key Features
* **Intro Animation**: Smooth screen blur, logo popup, swish animation, and red ambient gradient shift.
* **Built-in Key System**: Secure your scripts easily.
* **Smooth Tweening**: Built with custom `TweenService` easing styles and sound effects.
* **Extensive Components**: Tabs, Sections, Buttons, Toggles, Sliders, Textboxes, Keybinds, and Dropdowns.
